## Task 3: Create tasks/user.yml

**Files:**
- Create: `tasks/user.yml`

- [ ] **Step 1: Write user.yml**

```yaml
- name: Create neo user
  ansible.builtin.user:
    name: neo
    shell: /bin/zsh
    groups: sudo
    append: true
  when: ansible_facts['user_id'] != 'neo'

- name: Copy SSH authorized keys
  ansible.posix.authorized_key:
    user: neo
    state: present
    follow: false
  when: ansible_facts['user_id'] != 'neo'
  become: true
  become_user: neo

- name: Ensure sudo group exists
  ansible.builtin.group:
    name: sudo
    state: present
```

- [ ] **Step 2: Commit**

```bash
git add tasks/user.yml
git commit -m "feat: add user.yml for neo sudo user"
```

## Task 4: Create tasks/pyenv.yml

**Files:**
- Create: `tasks/pyenv.yml`

- [ ] **Step 1: Write pyenv.yml**

```yaml
- name: Install pyenv dependencies
  apt:
    name:
      - build-essential
      - zlib1g-dev
      - libssl-dev
      - libffi-dev
    state: present

- name: Clone pyenv
  ansible.builtin.git:
    repo: https://github.com/pyenv/pyenv.git
    dest: /home/{{ ansible_facts['user_id'] }}/.pyenv
    depth: 1
  when: ansible_facts['user_id'] != 'root'

- name: Setup pyenv in .zshrc
  ansible.builtin.lineinfile:
    path: /home/{{ ansible_facts['user_id'] }}/.zshrc
    line: 'export PYENV_ROOT="$HOME/.pyenv"'
    state: present
    create: true
  when: ansible_facts['user_id'] != 'root'
```

- [ ] **Step 2: Commit**

```bash
git add tasks/pyenv.yml
git commit -m "feat: add pyenv.yml"
```

## Task 5: Create tasks/nvm.yml

**Files:**
- Create: `tasks/nvm.yml`

- [ ] **Step 1: Write nvm.yml**

```yaml
- name: Install nvm
  ansible.builtin.shell: |
    curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash
  args:
    creates: /home/{{ ansible_facts['user_id'] }}/.nvm
  when: ansible_facts['user_id'] != 'root'

- name: Add nvm to .zshrc
  ansible.builtin.lineinfile:
    path: /home/{{ ansible_facts['user_id'] }}/.zshrc
    line: 'export NVM_DIR="$HOME/.nvm"'
    state: present
    create: true
  when: ansible_facts['user_id'] != 'root'
```

- [ ] **Step 2: Commit**

```bash
git add tasks/nvm.yml
```
